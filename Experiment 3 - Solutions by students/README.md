# BTCS301P - Experiment 3
## Implementation and Analysis of Spatial Filtering Techniques

This project implements:
- Average/Mean filtering
- Gaussian filtering
- Median filtering
- Laplacian filtering
- Sobel X and Sobel Y edge detection
- Salt-and-pepper noise generation
- Basic computational performance comparison

## Requirements
Python 3.x

Install dependencies:
pip install opencv-python numpy matplotlib

## Run
1. Put an image named `input.jpg` in this folder.
2. Run:
   python spatial_filtering.py

The program creates a `results` folder containing the filtered images and a comparison figure.
